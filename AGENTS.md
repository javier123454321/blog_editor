# AGENTS.md

Visual markdown editor for the 11ty blog at `blog/`. Bun workspaces monorepo; toolchain managed by `mise` (Bun 1.3.14).

## Production Deployment

See [`status/AGENTS.prod.md`](status/AGENTS.prod.md) for the full production deployment guide.
Progress logs: [`status/progress/`](status/progress/)

## Architecture (non-obvious)

- **The `blog/` directory is a git submodule** (git@github.com:javier123454321/blog.git), currently on `main`. All content edits, git operations, and PRs happen *inside the submodule* — never at the monorepo root. The editor repo only tracks submodule-pointer commits. Run `git submodule update --init --recursive` after cloning; checkout works inside `blog/`.
- `packages/server` is an Express API **interpreted by Bun — no build step** (`bun --watch src/index.ts`; its `build` script is a no-op echo). `packages/web` is Vue 3 + Vite **using Nuxt UI standalone** via the `@nuxt/ui/vite` plugin (not a Nuxt app); `@` aliases to `src/`, and `useToast`/`useColorMode`/components are auto-imported.
- `packages/server/src/lib/paths.ts` guards all user-supplied paths (`resolveWithin` rejects `..` traversal); keep using it for new file/git paths.

## Commands

Use `mise run …` (thin wrappers over `bun run --filter '*' …`). Run per-package with `--filter @blog-editor/server|@blog-editor/web`.

- `mise run dev` — runs API + web; also `dev:server` (:3001), `dev:web` (:5173), `dev:blog` (:5178, runs the blog submodule's eleventy+vite for the preview iframe).
- `mise run test` — server: `bun test` (node env). web: `vitest run`, only `src/**/*.test.ts`, colocated next to sources.
- Single test: `bun run --filter @blog-editor/server test src/lib/paths.test.ts` or `bun run --filter @blog-editor/web test src/lib/frontmatter.test.ts`.
- `mise run typecheck` — web (`vue-tsc --noEmit`) passes. Server (`tsc --noEmit`) **currently fails on a pre-existing error**: `HeadersInit` not found in `packages/server/src/services/github.ts:19`. Don't chase it unless your change caused it.
- `mise run lint` is a **no-op placeholder** in both packages (echo). Don't rely on it.
- The blog submodule is npm (own `package-lock.json`, `npm-run-all`, eleventy + vite), unlike the bun-managed root. `dev:blog` uses `npm --prefix blog run dev`.

## API / auth

- Every route except `/` and `POST /auth` requires header `X-Auth-Password: <plaintext>`; server compares its SHA-256 hash to `BLOG_EDITOR_PASSWORD_HASH` (`packages/server/src/middleware/auth.ts`). The web client stores the password in localStorage and always sends it.
- **The `/api` prefix is stripped** by both the Vite dev proxy and Caddy (`dev.computer.javiergonzalez.io`). Browser calls `/api/file?path=…` → server route `/file`. Don't add `/api/…` to Express route paths.
- In `app.ts`, the git router must stay mounted **before** the files router — `/file/remote` and `/file/discard` would otherwise be shadowed by the `/file/*` splat.
- `POST /commit` returns 400 "Nothing to commit" when the tree is clean; `/file/remote` and `/file/discard` read/restore against `origin/<base>`.

## Env / config

- Server loads the root `.env` (paths are hardcoded relative to `packages/server/src/config.ts`). Copy `.env.example` → `.env`. `BLOG_EDITOR_PASSWORD_HASH` is `echo -n "pw" | shasum -a 256`.
- `BLOG_DIR` (default `blog/src`), `GIT_DIR` (default `blog`), `IMAGES_DIR` (default `blog/src/images`) and `VITE_BLOG_PREVIEW_URL` (preview iframe, default `http://localhost:5178`) are overridable in `.env`.
- Images upload to `blog/src/images` and are referenced in markdown with the `/images` URL prefix.

## Conventions / gotchas

- `packages/web/auto-imports.d.ts` and `components.d.ts` are generated by unplugin and gitignored — never commit them.
- Frontmatter dirty-check baselines on the parsed+stringified content (`lib/frontmatter.ts`) so untouched files aren't flagged dirty; don't "fix" that comparison.
- `Caddyfile`: production `computer.javiergonzalez.io` reverse-proxies the deployed editor-server on :4096; dev host proxies `/api/*` → :3001 and everything else → :5173. Update Vite `server.allowedHosts` when adding dev domains.
- `.local_www/`, `.playwright-cli/`, `.scratch/` are local scratch/deploy artifacts — ignore them.
