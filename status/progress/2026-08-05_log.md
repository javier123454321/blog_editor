### 2. Fixed Server for Production
Three bugs discovered and fixed in `packages/server/src/app.ts`:

**Bug 1 — Static assets blocked by auth gate**
- `express.static` was mounted after `authGate`
- All JS/CSS files got 401'd, Vue never booted
- Fix: move `express.static` before `authGate`

**Bug 2 — API routes missing `/api` prefix**
- Frontend always fetches `/api/*` but server had routes mounted at `/*`
- `/api/auth` hit the auth gate and was rejected
- Fix: mount all routes under `/api`

**Bug 3 — SPA fallback in wrong position**
- Static + SPA fallback needed to be after API routes
- Fix: correct ordering — static → authGate+routes → SPA fallback
